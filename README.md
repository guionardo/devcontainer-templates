# Dev Container Templates

Catálogo de **templates reutilizáveis de Dev Containers** para projetos PHP. Este repositório **não contém código de aplicações** nem implementações de migração: apenas configurações de ambientes, Dockerfiles, scripts de provisionamento, documentação e, quando necessário, exemplos mínimos para validar o debug no VS Code.

## Templates planejados

- `php-5.1.6`: ambiente de referência para executar e depurar projetos legados.
- `php-5.4`: ambiente de referência para executar e depurar projetos legados.
- `php-8.5`: ambiente de desenvolvimento e depuração de projetos modernizados.

Os projetos reais vivem em seus próprios repositórios e aplicam o template adequado. Testes de regressão de regras de negócio pertencem aos repositórios das aplicações, não a este catálogo.
